# 功能蓝图 · dnshe域名续期

## 产品目标

免费域名最大的风险不是「没钱续」，是**忘了续**。DNSHE 免费域名到期后只留赎回期，过期久了直接回收。
本工具的目标：**让续期这件事彻底不需要人记着**。

三条原则：

1. 只在窗口内动手（180 天硬约束），不做无效请求。
2. 默认保守（阈值 30 天），但可以调到 0 天做到「一进窗口立刻续满一年」。
3. 所有动作留痕（日志 + history.jsonl），出问题能倒查。

## 能力矩阵

### V1（当前，已完成）

| 能力 | 入口 |
|---|---|
| 查看全部域名与到期情况 | `list` / 面板表格 |
| 紧急度分级（已过期/紧急/临近/窗口内/安全/永久） | 面板标签 + CLI 颜色 |
| 单域续期 | `renew <域名>` / 面板按钮 |
| 批量续期（窗口内全部 / 达到阈值） | `renew --all` `renew --due` / 面板按钮 |
| 演练模式（只看不动） | `--dry-run` |
| 无人值守自动续期 | `auto` |
| 定时执行 | Windows 计划任务 / cron / GitHub Actions |
| 结果通知 | Webhook（企业微信/钉钉/飞书/通用） |
| 运行日志 + 续期历史 | `logs/` `data/history.jsonl` `history` 命令 |

### V1.1（下一轮，按需）

- 续期前二次确认弹层，列出「域名 → 当前到期 → 续期后到期」
- 多账号支持（`accounts[]`，按账号分组查询与续期）
- 面板内直接填/改 API 凭据，不用回命令行
- 到期时间趋势记录（每次查询存快照，画出续期后的阶梯变化）

### V2（远期，不一定做）

- DNS 记录只读查看（A/CNAME/TXT），面板里展示，方便核对验证记录
- 域名即将到期但**不在窗口**时的提前提醒（纯通知，不动作）
- Telegram Bot 通知类型
- 多后缀批量注册（抢短域名），这属于另一个产品，暂不纳入

## 不做什么

- 不做域名抢注、不做批量注册。
- 不代理登录（不用账号密码模拟网页操作，只用官方 API）。
- 不做常驻服务（面板是本地工具，不是要长期跑的服务端）。
