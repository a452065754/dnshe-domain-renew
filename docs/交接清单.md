### Actions 环境与本地环境的差异（踩过）

| 项 | 本地 | Actions |
|---|---|---|
| 阈值 | `config.json` 里 180 | 靠 `DNSHE_THRESHOLD_DAYS: "180"` 环境变量，否则回落默认 30 |
| 凭据 | `config.json` | Secrets → 环境变量 |
| 运行环境 | Windows / Python 3.13 | `ubuntu-24.04` / Python 3.12 |
| action 版本 | — | checkout@v7 / setup-python@v7 / upload-artifact@v7（Node 24 版，v4/v5 会报 Node20 弃用告警） |

`config.json` 永不入库，改阈值要**同时**改本地配置和 workflow 里的环境变量。
