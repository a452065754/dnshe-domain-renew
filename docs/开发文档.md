> 技术事实记录。改动前先读本文件，避免重复踩坑。

## 1. 项目定位

DNSHE（dnshe.com）免费域名的到期查询 + 自动免费续期工具。
免费域名注册期 1 年，**到期前 180 天**开放免费续期窗口；窗口外调用续期会被后端拒绝。

形态：Python 3 标准库 CLI + 本地 Web 面板，零第三方依赖。

## 3. API 事实

```
基础地址  https://api005.dnshe.com/index.php?m=domain_hub&endpoint=<ep>&action=<act>
认证头    X-API-Key: <key>
          X-API-Secret: <secret>
```

| 用途 | 方法 | 参数 |
|---|---|---|
| 域名列表 | GET | `endpoint=subdomains` `action=list`，支持 `page`/`per_page`(≤500)/`fields=all`/`cursor_id`/`sort_by` |
| 域名详情 | GET | `endpoint=subdomains` `action=get&subdomain_id=N` |
| **续期** | **POST / PUT** | `endpoint=subdomains` `action=renew`，body `{"subdomain_id": N}` |
| 注册域名 | POST | `endpoint=subdomains` `action=create` |
| 删除域名 | POST / DELETE | `endpoint=subdomains` `action=delete`，body `{"subdomain_id": N}` |
| DNS 记录 | GET/POST | `endpoint=dns_records` `action=list|create|modify|delete` |
| 密钥列表 | GET | `endpoint=keys` `action=list`（**不返回 secret**） |
| 创建密钥 | POST | `endpoint=keys` `action=create`，body `{"key_name": "...", "ip_whitelist": "可选"}` |
| 重置 secret | POST | `endpoint=keys` `action=regenerate`，body `{"key_id": N}` |
| 配额 | GET | `endpoint=quota`（**没有 action 参数**） |
| WHOIS | GET | `endpoint=whois`（公开，2 请求/分钟/IP） |

**实测确认（2026-11-17，账号 7 个域名）**

`subdomains/list` 返回的真实字段：

```json
{
  "id": 199920,
  "subdomain": "xudd",
  "rootdomain": "ccwu.cc",
  "full_domain": "xudd.ccwu.cc",
  "status": "Registered",
  "created_at": "2026-02-03 02:36:33",
  "updated_at": "2026-05-18 15:41:33",
  "expires_at": "2036-02-03 10:36:33",
  "never_expires": 0,
  "cloudflare_zone_id": "ccwu.cc",
  "provider_account_id": 7
}
```

要点：

- 到期字段就是 `expires_at`；永久域名看 `never_expires`（0/1）。
- **`subdomain` 只是前缀**，完整域名在 `full_domain`，或 `subdomain + "." + rootdomain`。只取 `subdomain` 会显示成 `xudd` 而不是 `xudd.de5.net`。
- `status` 实际返回 `"Registered"`（首字母大写），代码里 `.lower()` 后比较。
- 续期成功返回：`message` / `subdomain_id` / `subdomain` / `previous_expires_at` / `new_expires_at` / `renewed_at` / `never_expires` / `status` / `remaining_days` / `charged_amount`(0=免费)。

续期成功响应字段：
`success`, `message`, `subdomain_id`, `previous_expires_at`, `new_expires_at`, `charged_amount`(0=免费), `remaining_days`

### 坑位（全部实测/官方文档确认）

1. **官方知识库第三步的续期命令是错的**：写的 `GET ...endpoint=dns_records&action=list&subdomain_id=1` 只是按 id 列 DNS 记录，不会续期。**真实续期是 `POST subdomains/action=renew`**，已实测成功。
2. **认证先于路由**：无凭据/错凭据时打任何 endpoint 都返回 `auth_invalid_credentials`，无法探测端点是否存在。实测：
   - 无 header → `Missing API credentials (use X-API-Key and X-API-Secret headers)` / 401
   - 假 key → `Invalid API key` / 401（**先校验 key**）
   - 真 key + 假 secret → `Invalid API secret` / 401
   - `Authorization: Bearer <key>` → `Missing API credentials` / 401（**不支持 Bearer**，Bearer 只用于 DDNS）
3. **API Secret 只在创建/重置时显示一次**，`keys/list` 不会返回 secret。丢了只能 regenerate 或新建 key。
4. **续期写操作不能自动重放**：续期是"到期日 +1 年"，重放会叠加成年限。代码里 renew 关闭了 retry，只在明确 405/501 时才换 POST→PUT。
5. **后端偶发 Cloudflare 520**：实测 `xudd.cn.mt` 第一次续期 520（源站错误），此时到期日未变（未生效），重试一次即成功。工具不自动重试 520，需要人工确认后再来一次。
6. 偶发首次请求慢，出现过 ~25s 超时后重试成功的情况（正常 1.7–2.3s）。

## 5. 关键设计决策

- **零依赖**：不引 requests/Flask，目标机器只要能跑 Python 就能跑，离线环境也不折腾。
- **续期形态探测但克制**：`renew()` 默认只发 POST，仅在明确 405/501（方法不支持）时才换 PUT，并记住生效形态。写操作关闭自动重试，防止重复续期把到期日叠成年限。
- **字段容错而非强假设**：`Domain.from_raw` 对 id/name/status/expires 全部走候选键列表，后端改字段名不至于直接崩。
- **阈值双条件**：可续期 = `进入 180 天窗口` AND `剩余天数 ≤ threshold_days`。窗口是硬约束（后端会拒），阈值是用户策略。
- **永久域名只认显式标记**：`never_expires=1`（或 `is_permanent` 等同义字段）才算永久，不靠"没有到期时间"猜——否则后端漏字段会被误判成永久而永不续期。
- **面板只绑 127.0.0.1**，不对外暴露 API 密钥；`config.json` 进 `.gitignore`。
- **pythonw 兼容**：`sys.stdout` 可能为 `None`，`main()` 开头兜底到 `os.devnull`；`_COLOR` 用 `getattr` 安全判断。

## 7. 实测结论（2026-11-17 首次真实联调）

账号共 7 个域名，全部拿到，续期 3 个成功。

| 待确认项 | 结论 |
|---|---|
| 续期接口形态 | **`POST subdomains/action=renew` 可用，已实测成功 3/3**（GET 形态不是官方支持方式，代码已移除） |
| 到期字段键名 | `expires_at`，无需扩充 `_EXPIRES_KEYS` |
| 永久域名字段 | `never_expires`（0/1），已接入判定 |
| 限流 | 官方文档 60 请求/分钟，实测 4 次请求 1 分钟内无异常；面板保留 20s 缓存 |
