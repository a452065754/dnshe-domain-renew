3. 后端偶发 Cloudflare 520，续期此时未生效，人工重试即可（工具不自动重试写操作）。
4. `config.json` 含密钥，已进 `.gitignore`，别提交。
5. 面板每次 `/api/state` 会打真实 API，已加 20s 缓存。
